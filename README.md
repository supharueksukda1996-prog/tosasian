# ม้วนคัมภีร์แห่งออเรเลน

เกมเล่าเรื่องสำหรับงานจบแล้วไปไหน คณะแพทยศาสตร์ มหาวิทยาลัยขอนแก่น เล่นบนมือถือผ่านเบราว์เซอร์ ผู้เล่นเดินทางหาอุปกรณ์ปราบจอมมาร แล้วสุ่มได้สาขาที่ต้องไปหาในงาน

## แก้เนื้อหา
แก้ได้ที่ `data.js` ไฟล์เดียว ได้แก่ บททุกฉาก ตัวเลือก อุปกรณ์ และนิสัย คำทำนาย คำถามของทั้ง 16 สาขา

## ใส่รูปการ์ตูนของสาขา
รูปอยู่ในโฟลเดอร์ `images` และกำหนดผ่านค่า `img` ของแต่ละสาขาใน `data.js` ใช้รูปสี่เหลี่ยมจัตุรัสพื้นหลังโปร่งใส ถ้าเว้นว่างเกมจะแสดง emoji แทน

## ตัวละคร
รูปผู้พูดและตัวแทนทั้ง 16 สาขาอยู่ใน `art/characters` ถ้าเพิ่มผู้พูดใหม่ ให้เพิ่มชื่อกับรูปใน `speakers` ของ `data.js` โดยชื่อต้องตรงกับผู้พูดในบท ส่วนตัวแทนสาขากำหนดที่ค่า `hero`

## ลองเล่นในเครื่อง
```bash
python -m http.server 8765
```
แล้วเปิด http://localhost:8765

## เปิดรับข้อมูลลง Google Sheets
1. สร้าง Google Sheet ใหม่ แล้วเปิด ส่วนขยาย > Apps Script
2. วางโค้ดจาก `apps-script.gs` แล้วบันทึก
3. กด Deploy > New deployment > Web app ตั้ง Execute as เป็น Me และ Who has access เป็น Anyone
4. คัดลอก URL ที่ได้ไปใส่ใน `endpoint` ที่ต้นไฟล์ `data.js`

ตอนนี้ยังไม่เปิดเก็บข้อมูล เมื่อใส่ `endpoint` แล้วเกมจะถามชั้นปีและแสดงข้อความแจ้งเรื่องข้อมูลให้เอง ข้อมูลที่เก็บ: เวลา รหัสรอบเล่นแบบสุ่ม ชั้นปี ตัวเลือกในเรื่อง สาขาที่ได้ และเวลาที่ใช้ ชื่อบนการ์ดไม่ถูกส่งออกจากเครื่อง

## เผยแพร่
อัปโหลด `index.html`, `style.css`, `data.js`, `scenes.js`, `game.js` และไฟล์ `.webp` ในโฟลเดอร์ `art` กับ `images` ขึ้น static hosting เช่น GitHub Pages หรือ Netlify แล้วสร้าง QR code จากลิงก์นั้น ไม่ต้องอัปโหลด `art/source`, `images/source`, `old-train`, `story-script.md`

## โฟลเดอร์อื่น
- `art/source` และ `images/source` ภาพต้นฉบับความละเอียดเต็ม
- `old-train` เกมธีมรถไฟรุ่นก่อน เก็บไว้อ้างอิง
