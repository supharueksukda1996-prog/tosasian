# ศึกทศเศียร: ตำนานผู้เยียวยาแห่งกองทัพ

เกมเล่าเรื่องสำหรับงานจบแล้วไปไหน คณะแพทยศาสตร์ มหาวิทยาลัยขอนแก่น เล่นบนมือถือผ่านเบราว์เซอร์ ผู้เล่นเป็นผู้เยียวยาในกองทัพที่ออกเดินทางไปปราบราชาอสูร (เรื่องคู่ขนานที่ได้แรงบันดาลใจจากรามายณะ) ตอบคำถาม 16 ข้อระหว่างทาง แล้วได้การ์ดสาขาที่เหมาะกับบุคลิก

## การคิดผล
1. ตัวเลือกแต่ละข้อให้คะแนน 6 มิติ ได้แก่ หัตถะ ปัญญา เมตตา ฉับไว อดทน และมองไกล
2. คะแนนรวมแต่ละมิติถูกแปลงเป็น 0 ถึง 1 ตามคะแนนสูงสุดที่เป็นไปได้
3. เกมเทียบรูปทรงบุคลิกของผู้เล่นกับ `profile` ของแต่ละสาขา (cosine similarity หลังลบค่าเฉลี่ย) แล้วบวก `bias`
4. สาขาที่ได้คะแนนสูงสุดคือผลลัพธ์ ส่วนความหายากสุ่มตาม `rareRate`

`bias` มีไว้ปรับให้แต่ละสาขาออกบ่อยใกล้กัน คำนวณใหม่ได้ที่หน้า `admin.html`

## ชีตตั้งค่า
ปรับค่าได้โดยไม่ต้องแก้โค้ด:
1. สร้าง Google Sheet ใหม่ แล้วนำเข้าไฟล์ทั้งหมดใน `sheet-template` เป็นแท็บละไฟล์ ชื่อแท็บ `settings`, `specialties`, `questions`
2. ไปที่ ไฟล์ > แชร์ > เผยแพร่ไปยังเว็บ เลือกทีละแท็บ รูปแบบ CSV แล้วคัดลอกลิงก์
3. ใส่ลิงก์ใน `sheet` ที่ต้นไฟล์ `data.js` แล้วอัปโหลดขึ้นเว็บหนึ่งครั้ง
4. หลังจากนั้นแก้ค่าในชีตได้เลย เกมจะอ่านค่าใหม่ทุกครั้งที่เปิด (Google อาจใช้เวลาไม่กี่นาทีกว่าค่าจะอัปเดต)

ถ้าโหลดชีตไม่ได้ภายใน 3.5 วินาที เกมจะใช้ค่าใน `data.js` แทน ก่อนวันงานให้เปิด `admin.html` เพื่อตรวจว่าค่าไม่มีปัญหาและทุกสาขามีโอกาสออก

สร้างไฟล์ CSV ใหม่จากค่าใน `data.js`:
```bash
node tools/make-sheet-template.js
```

บทเล่าของแต่ละฉากยังแก้ได้เฉพาะใน `data.js`

## รูป
- `images` ตราการ์ตูนของแต่ละสาขา
- `art/characters` ผู้พูดและตัวแทนทั้ง 16 สาขา ภาพการ์ด Rare แยกต่างหากใส่ได้ที่ค่า `heroRare` ถ้าเว้นว่างจะใช้ภาพปกติพร้อมกรอบทองและฟอยล์
- `art` ภาพฉาก

## ลองเล่นในเครื่อง
```bash
python -m http.server 8765
```
แล้วเปิด http://localhost:8765 และหน้าตรวจค่าที่ http://localhost:8765/admin.html

## เปิดรับข้อมูลลง Google Sheets
1. สร้าง Google Sheet ใหม่ แล้วเปิด ส่วนขยาย > Apps Script
2. วางโค้ดจาก `apps-script.gs` แล้วบันทึก
3. กด Deploy > New deployment > Web app ตั้ง Execute as เป็น Me และ Who has access เป็น Anyone
4. คัดลอก URL ที่ได้ไปใส่ใน `endpoint` ที่ต้นไฟล์ `data.js`

ตอนนี้ยังไม่เปิดเก็บข้อมูล เมื่อใส่ `endpoint` แล้วเกมจะถามชั้นปีและแสดงข้อความแจ้งเรื่องข้อมูลให้เอง ชื่อบนการ์ดไม่ถูกส่งออกจากเครื่อง

## โฟลเดอร์ที่ไม่อัปโหลด
- `art/source` และ `images/source` ภาพต้นฉบับความละเอียดเต็ม
- `old-train` เกมธีมรถไฟรุ่นแรก

## อัปเดตเว็บให้ทุกเครื่องเห็นของใหม่
ทุกครั้งที่แก้ไฟล์เกม ให้รัน `python tools/bump-version.py` ก่อน commit หน้าเว็บจะเช็ก version.txt แล้วโหลดใหม่เองถ้าเครื่องผู้เล่นยังจำหน้าเก่าไว้
